# 一起去 · 周末城市探索指南

基于「一起去」（J人计划规划工具）的 J/P 双模式内核，面向"大学生周末去哪玩"场景的独立产品雏形。

## 产品结构

```
入口选节奏（P 随心收集 / J 好好安排，随时切换）
├── 🧭 发现      天气+预算+偏好推荐流，P=丢进口袋 / J=排入课表
├── 🎒 计划      P→周末口袋（随心收集）  J→周末课表（六/日×时段+预算汇总）
├── 👥 组队      J 式定档组队 / P 式随心喊人
├── 📍 打卡      待打卡（来自课表+口袋）+ 打卡墙 + 足迹统计
├── 📝 攻略      攻略流，可"收进口袋"或"照着排进课表"
└── 🙂 我的      兴趣偏好 + 预算线设置
```

推荐引擎（`js/app.js` → `recommend()`）：评分 = 口碑基础分 + 天气适配（雨天户外扣分）+ 预算匹配 + 兴趣标签 + 距离加权，并生成推荐理由。

## 运行

纯静态站点，无构建依赖。任选其一：

```bash
# 直接双击 index.html 即可打开（file:// 可用）
# 或起本地服务：
python3 -m http.server 8080
```

## 目录结构

```
yiqi-weekend/
├── index.html        页面骨架 + tab 导航
├── css/style.css     全部样式（设计变量见 :root）
├── js/data.js        数据层：分类色、地点/评价、队伍、攻略 mock
├── js/app.js         应用层：状态+localStorage、推荐引擎、5 个视图渲染、弹窗
└── README.md
```

用户数据（口袋/课表/组队/打卡/攻略/偏好）持久化在 `localStorage`（key: `yiqi_weekend_v1`）。
